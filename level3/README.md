# Level 3

세 번째 단계는 텍스트 응답을 A2UI 렌더링으로 바꾼다.

- `handson/`: A2UI schema prompt와 callback 연결 실습
- `solution/`: A2UI JSON을 생성하고 UI 파트로 감싸는 완성본
- 핵심 주제: `A2uiSchemaManager`, `after_model_callback`, `application/json+a2ui`

주요 파일:

- `crypto_dashboard/agent.py`
- `crypto_dashboard/a2ui_utils.py`
- `crypto_dashboard/market_data.py`
